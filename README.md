# Python libraries, Data Visualization & Data Analysis

## Python Libraries

 NumPy – Numerical operations and calculations.
 Pandas – Data cleaning, handling missing values, and data analysis.
 Matplotlib – Creating charts and plots for data visualization.
 Seaborn – Creating statistical visualizations such as box plots, heatmaps, and count plots.

### NumPy

 NumPy (Numerical Python) is a Python library mainly used for numerical and mathematical operations.

### Important points:

- Works with arrays.
- Faster than normal Python lists for numerical operations.
- Supports 1D, 2D, and multi-dimensional arrays.
- Provides mathematical and statistical functions.
- Useful for data analysis and scientific computing.
  
### How to import Numpy

 import numpy as np

### Common functions

np.array()
np.mean()
np.median()
np.std()
np.var()
np.random
np.reshape()
np.concatenate()
np.split()

## Pandas

 Pandas is a Python library mainly used for data manipulation, data cleaning, and data analysis.

### Important points:

- Works mainly with Series and DataFrame.
- DataFrame looks like a table with rows and columns.
- Can read data from CSV, Excel, SQL, etc.
- Helps with missing values, duplicates, filtering, grouping, and sorting.
- Very commonly used in Data Analytics.

### How to import pandas
 
- import pandas as pd

## Datastructures in pandas:

  Series and DataFrame are the two main data structures in Pandas.
  
- Series → 1-dimensional data structure (one column)
- DataFrame → 2-dimensional data structure (rows and columns)
  
## Matplotlib: 

 Matplotlib is a Python data visualization library used to create charts and graphs. It provides detailed control over titles, labels,     colors, axes, and chart formatting.
 
### How to import matplotlib:import matplotlib.pyplot as plt

### Common Matplotlib chart types:

1. Bar chart:Compares values across categories.
2. Histogram:Shows the frequency distribution of numerical data.
3. Scatter plot:Shows the relationship between two numerical variables.
4. Line chart:Shows trends or changes across an ordered sequence, often time.
5. Pie chart:Shows how categories contribute to a whole.
6. Box plot:Summarizes the median, quartiles, spread, and potential outliers.
   
## Seaborn: 

Seaborn is a Python statistical visualization library built on Matplotlib. It makes it easier to create attractive charts and explore relationships, distributions, and patterns in datasets.

### How to import seaborn: import seaborn as sns 

### Common seaborn chart types:

1. Count plot:Counts the number of observations in each category.
2. Box plot:Compares numerical distributions across categories and highlights potential outliers.
3. Heatmap:Uses colors to represent values in a matrix, often to display correlations.
4. Pair plot:Displays pairwise relationships between several numerical variables, with distributions along the diagonal.
5. Violin plot:Shows the distribution and density of numerical values across categories.
6. Scatter plot:Shows the relationship between two numerical variables. The hue parameter can distinguish categories using colors.

## Project Overview

This project analyzes social media data to understand user engagement, content performance, and audience behavior. Using Python and Pandas, the dataset was cleaned and explored to identify patterns in likes, comments, shares, engagement rates, and watch time.

Tools & Technologies
- Python
- Pandas
- NumPy

## Key Tasks
- Handled missing values and duplicate records.
- Cleaned and prepared data for analysis.
- Performed statistical analysis and exploratory data analysis (EDA).
- Analyzed engagement by post type, content category, country, age group, device type, and sentiment.
- Created visualizations to identify trends and patterns.

## Key Findings
- Video posts achieved the highest average engagement score.
- Music was the best-performing content category by average engagement score.
- Brazil recorded the highest average engagement rate among the countries analyzed.
- Users aged 46–60 had the highest average engagement rate.
- Mobile users recorded the highest average watch time.
- Negative posts showed the highest average engagement rate.
