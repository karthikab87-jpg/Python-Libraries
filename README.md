## Libraries using in Python

# NumPy

 NumPy (Numerical Python) is a Python library mainly used for numerical and mathematical operations.

# Important points:

- Works with arrays.
- Faster than normal Python lists for numerical operations.
- Supports 1D, 2D, and multi-dimensional arrays.
- Provides mathematical and statistical functions.
- Useful for data analysis and scientific computing.
  
## How to import Numpy

import numpy as np

## Common functions

np.std()
np.var()

np.concatenate()
np.split()

# Pandas

 Pandas is a Python library mainly used for data manipulation, data cleaning, and data analysis.

## Important points:

- Works mainly with Series and DataFrame.
- DataFrame looks like a table with rows and columns.
- Can read data from CSV, Excel, SQL, etc.
- Helps with missing values, duplicates, filtering, grouping, and sorting.
- Very commonly used in Data Analytics.

## How to import pandas
 
- import pandas as pd

## Datastructures:

- Series and DataFrame are the two main data structures in Pandas.

- Series → 1-dimensional data structure (one column)
- DataFrame → 2-dimensional data structure (rows and columns)

## Data Visualization

### Data visualization is the process of representing data in a visual form, such as charts, graphs, and plots, to understand data easily.

## Importance of Data Visualization

- Helps us understand data quickly.
- Identifies patterns and trends.
- Helps detect outliers.
- Makes it easier to compare data.
- Supports better decision-making.

## Different Charts for plotting

### Bar chart
- Compare values between categories
### Count plot
- Count observations in categories
### Histogram
-	Understand numerical distributions
### Line chart
- Show trends over time
### Scatter plot
-  Examine relationships between two numerical variables
### Pie chart
- Show proportions
### Box plot
-Understand spread and potential outliers
### Heatmap
- Represent values or correlations using colours
### Pair plot
- Explore relationships among multiple variables
### Violin plot
- Explore distributions and density across categories
